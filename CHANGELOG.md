# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2026-01-16

### Added
- Initial release
- QLoRA fine-tuning with Unsloth optimization
- Multi-GPU support via DeepSpeed ZeRO
- Dataset conversion utilities (Alpaca, ShareGPT, OASST, Dolly)
- MLflow experiment tracking
- Learning rate finder
- Advanced metrics and evaluation
- Benchmark suite
- Comprehensive documentation
- Unit tests with pytest
- CI/CD with GitHub Actions
- Docker support
- Performance benchmarks

### Features
- 4-bit quantization with QLoRA
- RS-LoRA support
- Checkpoint recovery
- Multi-mode inference (chat, batch, single)
- VRAM estimation
- Automatic dataset validation
- Sample packing for efficiency
- Multiple training presets
